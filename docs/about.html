What this is.

CompuCon is a tech camp for middle and high school students at Lane Community College. This is the vibe coding track — four sessions where campers describe apps in plain English and an AI writes the code.

the camps

LCC summer camps

Lane Community College runs summer camps for middle and high school students every year. CompuCon is one of them. The full list is on the LCC site:

LCC summer camps CompuCon and the other camps, at lanecc.edu.
the camp

CompuCon

CompuCon is the coding camp. Each track covers a different topic. This track is about building real apps — with an AI helping to write the code.

the skill

Vibe coding

Vibe coding is building software by describing what you want in plain English and letting an AI write the code. The interesting part: the AI is often wrong. So campers learn to check what they get back, find what broke, and say exactly what to fix.

the tool

Claude Code

The AI campers work with is Claude Code, a coding assistant from Anthropic. You talk to it in a terminal and it writes and changes files in your project. Campers steer it and check its work — that skill keeps working no matter how the tools change.

This website was produced using Claude Code.
